# M1/M2 synthetic benchmark (2026-11-17)

Machine: Linux x86-64, Python 3.12.15, 8 GiB system RAM, warm local filesystem. `uv run python scripts/benchmark.py` generated 10,000 targets and 50,000 directed acyclic build edges using seed 42. SQLite import took 2.299 s. One hundred random direct edge queries had p95 116.622 ms. Iterative SCC took 0.154 s and found zero cycles. M2's 200-target overview took 110.934 ms; a depth-2 bounded neighborhood (144 returned targets) took 302.933 ms. Peak process RSS (`/proc/self/status` VmHWM) was 204,328 kB. CMake configuration and File API extraction are separate from this synthetic import measurement. These results do not establish 2M-LOC or Windows performance.
